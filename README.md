# 나의 하루 방 · 2B

`index.html`을 브라우저에서 열어 사용하는 날짜별 방 일기장입니다.

첫 방문에는 화면 작동을 확인할 수 있도록 한국어 예시 기록이 표시됩니다. 예시 기록은 방문자의 브라우저에만 저장되며, 실제 사용자는 날짜별 기록을 직접 작성하고 저장할 수 있습니다.

## 열기

`index.html` 파일을 브라우저에서 엽니다. 이미지 파일은 `assets` 폴더와 함께 두어야 합니다.

## 기록과 수정 내역

- `AI-2B-prompt.md`: 2B AI 입력 지시문
- `2B_수정기록.md`: 개선 방향과 전후 수정 기록
- `evidence/`: 2A 화면과 수정 참고 캡처

## 카메라 움직임

기존 방 사진과 배치는 유지합니다. 마우스로 누른 채 드래그하면 깊이 시차로 앞쪽과 뒤쪽이 조금 다르게 움직입니다. 이 기능은 사진 기반 2.5D 표현이며, 사진에 없는 방의 옆면까지 볼 수 있는 완전한 3D 모델은 아닙니다.

## 현재 깊이 메시 구성
기존 방 사진을 색상 텍스처로 사용하고, 창밖·소파·책상·주요 물건에 서로 다른 깊이를 적용한 세분화 메시로 구성합니다. 마우스를 누르고 드래그하면 메시의 시점이 제한된 범위에서 바뀌고, 핫스팟도 사진 속 물건 위치를 따라 움직입니다. 한 장의 사진으로 만든 2.5D 모델이므로 사진에 없는 물건의 뒷면이나 방의 옆면까지 보여 주지는 않습니다.
