2B 当前交互版（第59版）

打开方式（两种都可以）：
1. 推荐双击“打开2B网页.bat”，再用浏览器打开 http://127.0.0.1:8765/ （需要电脑装有 Python）。这样每次使用同一个地址，日记存储更稳定，网页也无需加载 file:// 专用的大型嵌入资源。
2. 没有 Python 时，可直接双击 index.html 打开。请始终在同一个浏览器里、从同一个文件夹打开；不要使用无痕模式，也不要清除该网页的浏览器数据。

日记输入后会自动保存，关闭网页前也会再次保存。文字另外保存在当前浏览器的本地备份中；照片、绘画、音频和视频仍依赖浏览器数据库。网页不会把记录同步到其他浏览器或电脑。旧记录若是用 file:// 地址写的，改用 http://127.0.0.1:8765/ 后不会自动出现，因为浏览器把它们视作两个不同的网站；先在原地址检查旧记录。

注意：请整个文件夹一起解压，不要单独移动 index.html；assets 和 lib 文件夹需要和网页放在一起。
点左边的门（情绪画廊）可以进入画廊场景，左上角“← 房间”返回。
画廊里的七幅名画挂在做旧的巴洛克雕花金框里，对应本周周一到周日的日记；点击画可以放大，并打开复古皮面日记本查看当天的手写日记（支持韩文手写字体，离线可用）。名画图片需要联网加载（其中四幅有本地副本）。

快捷键：N 写日记；在房间里按 C（或点击显示器）使用电脑，U 上传视频，空格 播放/暂停，Esc 返回。
