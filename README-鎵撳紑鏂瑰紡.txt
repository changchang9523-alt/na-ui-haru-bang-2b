2B 当前交互版（第54版）

打开方式（两种都可以）：
1. 直接双击 index.html 即可打开（推荐，不需要安装任何东西）。
2. 或双击“打开2B网页.bat”，浏览器会打开 http://127.0.0.1:8765/ （需要电脑装有 Python）。

注意：请整个文件夹一起解压，不要单独移动 index.html；assets 和 lib 文件夹需要和网页放在一起。
点左边的门（情绪画廊）可以进入画廊场景，左上角“← 房间”返回。
画廊里的七幅名画挂在做旧的巴洛克雕花金框里，对应本周周一到周日的日记；点击画可以放大，并打开复古皮面日记本查看当天的手写日记（支持韩文手写字体，离线可用）。名画图片需要联网加载（其中四幅有本地副本）。

快捷键：N 写日记；在房间里按 C（或点击显示器）使用电脑，U 上传视频，空格 播放/暂停，Esc 返回。
